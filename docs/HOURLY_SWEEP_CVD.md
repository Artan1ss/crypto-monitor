# 1H 扫点收回 + 现货/合约分裂背离

独立规则版本 `h1-sweep-split-cvd-v1`。生产默认 `HOURLY_STRATEGY=sweep`，仅评估并投递扫点信号，替代旧1H压力/背离通知。`pressure` 为旧分支回滚选项，`combined` 仅作对比研究。旧压力阈值没有重新拟合。

`HOURLY_ENABLED=true`、`HOURLY_TELEGRAM_ENABLED=true`、全局 `TELEGRAM_ENABLED=true` 时才启用生产通知。切换后旧队列中尚未投递的候选标记 `superseded_strategy`，不补发、不删除历史；旧策略记录不参与新扫点的4H冷却。历史回放不通知，原始输入可用时间、鲜价、失效与去重保护仍然生效。单机图表预览仍不运行信号服务或TG。

## 规则

- 最多168小时上下文；最少25个连续已收盘价格小时。摆动点左2右1，右确认必须在触发小时前完成。
- LONG：扫过一个尚未被穿越的已确认低点，收盘回到该低点上方；SHORT镜像。
- 多个价位同时被收回时，固定选最近形成的合格锚点，再检查CVD，不根据后续涨跌或CVD挑选更有利的锚点。
- 两市场均使用该**价格摆动小时的收盘**作CVD锚点，累计其后至触发小时的delta。LONG要求现货delta≥0、合约delta<0；SHORT反向。不是找两个市场各自不同时间的CVD极值，也不是影线触及时的逐笔CVD。
- 整个锚点区间必须同源、同交易所集合、已核验BTC单位、完整无缺口。逐小时 `|delta|≤volume`、volume>0；不通过极小normalizer制造背离。
- 同一锚点第一次被价格穿越即消耗，不因下一小时继续扫低重复提醒。形成新确认摆动点才获得新事件。这意味着第一次扫低未收回、稍后才收回的情况**本版本不会捕捉**。
- 原压力分支同方向候选被新扫点确认替代，避免同小时两次通知。仍沿用现有通知冷却、鲜价、持久化快照和结果追踪机制。
- 失效参考沿用扫点极值外0.2 ATR，不根据这次后续走势扩大。不是保证不被扫损的交易止损。

证据分满分100：扫点收回30、跨市场分裂30、收回幅度/ATR最多20、现货交易所方向一致性最多10、成交量相对前20小时中位数最多10。分数不经过概率校准，不是胜率或仓位建议。OI、费率保留作背景，不推断持仓方向。

## 本地查看与复现

运行 `python -m btc_monitor.hourly.preview`，打开 http://127.0.0.1:8011/dashboard ，点击“扫点背离验证（不发 TG）”。图表和账本会切入事后研究模式，点击LONG/SHORT箭头查看证据、收盘参考情景方向分/结构分，并可下载单信号快照。“返回在线”恢复实时行情；研究模式不会自动刷新或发送TG。

### 交互K线

1H和4H/日线共用 `CandleViewport`。六个1H面板同步拖动平移、滚轮缩放；左右键平移、加减键缩放、Home/End跳至已加载数据两端、双击回到最新100根。底部滑块浏览已加载范围，日期跳转输入明确使用UTC，图表标签使用多伦多时间。工具栏可显示全部已加载K线、按时间前后导航信号、同时定位选中信号及其摆动锚点。黄线标记真实时间缺口；缺口时间压缩排列，不补K线、不连接缺口两侧CVD。

LONG绿箭头位于触发K线下方，SHORT红箭头位于上方，同根同向信号分层排列。箭头位置使用 `bar_start`，并非实际生成/理论评估时间；后者仍在提示和详情中独立显示。选中时显示参考价、失效价、冻结锚点与被扫结构线，点击/键盘Enter或空格打开原始快照。

CVD先按全部已加载历史计算，再切取视窗，不因平移或缩放改变累计起点。实时刷新时，浏览旧数据会保留同一历史锚点；停在最右端则随新K线更新。更换实时/归档/研究数据集会重置视窗，避免错误复用另一集合的时间索引。这个界面不是TradingView嵌入服务，没有新增订阅/API；“全部”仅指已加载数据，实时入口仍最多168小时。

```powershell
python -m btc_monitor.hourly.sweep_research --output .research-data/h1-sweep-new-run.json.gz
```

命令只读取固定本机行情接口、生成新文件，不写信号表、不发送TG；文件已存在会拒绝覆盖。`--input`可读取之前保存的原始 `btc-hourly-market-v1` JSON复现。小时收盘参考价情景不包含实际3分钟延迟成交，不计手续费滑点；同小时同时触及目标与失效保持先后不明。12/24H未到期不打终点方向分，缺口前不确定的触及不算已证实。
